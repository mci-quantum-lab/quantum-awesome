# Contributing to Quantum Awesome

Thanks for wanting to contribute! A few simple guidelines to keep the list high quality:

## Adding a resource

1. Fork the repo and create a new branch.
2. Add your entry to the relevant section in `README.md`, in alphabetical order within its section when practical.
3. Use the format:
   ```markdown
   - [Resource Name](https://link-to-resource) — One-sentence description of what it is and why it's useful.
   ```
4. Make sure the link works and points to an official/primary source (project homepage, original paper, official docs) rather than a random blog mirror.
5. Open a pull request describing what you added and why it belongs on the list.

## Adding a new category

If a resource doesn't fit an existing category and you believe a new category is warranted:

1. Open an issue first to discuss it.
2. If agreed, add the new section to the Table of Contents and the body of `README.md`, keeping the existing structure and heading style.

## Quality bar

- No dead links.
- No promotional/spammy content — resources should have genuine educational, research, or practical value.
- Prefer primary sources (official docs, original papers) over secondary summaries when both exist.
- Keep descriptions concise (one sentence).

## Code of Conduct

Be respectful and constructive in issues and pull requests.
